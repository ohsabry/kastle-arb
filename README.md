# kastl-arb

Modified firmware source for the Bastl Kastle ARP's VCO chip that plays maqams with quarter tones
instead of major triads.

`kastl-arb.ino` is the modified sketch. `stock/kastleArp.ino` is Bastl's unmodified original, and the
git history shows every change between them.
